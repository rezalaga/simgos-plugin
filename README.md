# SIMGoS2 Plugin Repository

Kumpulan plugin dan modul ekstensi mandiri (*Zero Core Modification*) untuk Sistem Informasi Manajemen Rumah Sakit Generasi Open Source (SIMGoS2).

Repository ini disinkronkan ke:
- **GitHub**: https://github.com/rezalaga/simgos-plugin.git
- **GitLab**: https://dev.marthafriska.com/simgos/plugin/simgos-plugin

## Daftar Plugin:
1. **audit-rekam-medis**: Modul Audit Kelengkapan & Kualitas Rekam Medis Elektronik (RME) dengan kalkulasi persentase kelengkapan, deteksi data anomali, fast-lane direct editing, serta installer paket RPM (`simpel-audit-rekam-medis-1.0.0-26111800.x86_64.rpm`).
